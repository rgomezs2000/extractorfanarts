# Guía rápida

De cero a tener imágenes guardadas, en cinco pasos.

## 1. Elige el tipo y la plataforma

- **Tipo:** *Red social*, *Booru* o *Wiki fandom*.
- **Plataforma:** el sitio concreto (la lista cambia según el tipo).

## 2. Escribe lo que buscas

| Tipo | Qué escribir |
|---|---|
| **Red social** | `@usuario`, palabras clave y/o `#hashtags`. Puedes combinarlos y poner **varios valores** en un campo (separados por espacios o comas): se busca todo a la vez |
| **Booru** | etiquetas separadas por espacios o comas (`lola_loud 1girl solo`). Valen los operadores del sitio: `-etiqueta` para excluir, `rating:general`, `score:>10` |
| **Wiki** | el fandom, el personaje y/o la URL de la wiki |

**En el fediverso** no hace falta elegir servidor: escribe `@usuario@servidor`
(por ejemplo `@alguien@baraag.net`); o escribe `@usuario` y rellena *Instancia*.

## 3. Busca y revisa

Pulsa **🔍 Buscar** (`Ctrl+B`, o `Enter` en cualquier campo). Los resultados
aparecen en una **galería**: contador, imagen grande, tira de miniaturas y **una
casilla por resultado**. Pulsa la imagen grande para abrir el **visor** (`rueda`
para zoom, `arrastrar` para mover, `←`/`→` para cambiar, `Esc` para cerrar).

Así puedes **descartar antes de descargar nada**.

## 4. Ajusta y descarga

- **🔢 Limitar cantidad:** descarga solo las que indiques (1–1000).
- **✨ Mejorar calidad:** reescala según el tamaño de partida (ver
  [Calidad y mejora](Calidad-y-mejora)).
- **🤖 Modo IA:** usa Real-ESRGAN / waifu2x si vienen en el paquete.
- **🏷️ Guardar metadatos .json:** un `.json` por imagen con sus etiquetas (clave
  para [datasets](Datasets-IA)).
- **Salida:** la carpeta de destino. Puedes cambiarla con **📂 Carpeta** o `Ctrl+O`.

Pulsa **⬇️ Descargar** (`Ctrl+D`, o `Shift+Enter`). Te pedirá confirmación y al
terminar te dirá **cuántos archivos guardó y dónde**. Durante el trabajo, el
botón se convierte en **⏹️ Cancelar** (`Esc` también cancela) y **no deja
archivos a medias**.

## 5. Guarda una sola imagen (opcional)

**Clic derecho** sobre cualquier imagen (la grande, una miniatura o dentro del
visor):

| Opción | Atajo |
|---|---|
| 📋 Copiar imagen (ya procesada) | `Ctrl+C` |
| 💾 Guardar imagen (solo esa) | `Ctrl+S` |
| 🗂️ Guardar como… (eliges carpeta y nombre) | `Ctrl+Shift+S` |
| 🌐 Abrir la imagen original en el navegador | — |
| 🔗 Copiar el enlace original | `Ctrl+Shift+C` |

Funciona **aunque solo hayas pulsado Buscar**, y con la **misma política de
calidad** que la descarga completa.

## La barra de herramientas

Arriba tienes los accesos directos a todo lo importante:

| Botón | Atajo | Qué hace |
|---|---|---|
| 🔍 **Buscar** | `Ctrl+B` | busca con el criterio del formulario |
| ⬇️ **Descargar** / ⏹️ **Cancelar** | `Ctrl+D` | descarga lo encontrado; mientras trabaja, cancela |
| 🧹 **Limpiar** | `Ctrl+L` | vacía el formulario |
| 📂 **Carpeta** | `Ctrl+O` | elige la carpeta de salida |
| 🛡️ **Filtros** | — | explica qué se filtra y por qué |
| 📖 **Ayuda** | `F1` | abre el manual dentro del programa |
| 🔄 **Actualizaciones** | — | busca e instala la versión nueva |
| ℹ️ **Acerca de** | — | versión, licencia, autor y rutas |

Los botones se apagan y se encienden **a la vez** que los del formulario: si algo
no se puede pulsar, en la barra tampoco.

## Atajos de teclado

| Tecla | Dónde | Qué hace |
|---|---|---|
| `Enter` | en cualquier campo de búsqueda | **Buscar** |
| `Shift+Enter` | igual | **Descargar** |
| `Enter` | en el campo **Salida** | elegir carpeta |
| `Enter` o `Esc` | mientras busca o descarga | **cancelar** |
| `Esc` | con el visor abierto | cerrarlo |
| `F1` | en cualquier parte | abrir la ayuda |
| `Ctrl+Q` / `Alt+F4` | en cualquier parte | cerrar el programa |
