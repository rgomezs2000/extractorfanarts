# 🆘 Foro · Soporte técnico

**Para qué:** dudas de uso y **asistencia técnica** —«¿cómo hago para…?», «no me
funciona X», «¿qué casilla marco?»—.

Si es un **fallo** (algo que debería funcionar y no funciona), mejor en
[Fallos](Foro-Fallos). Si es una **idea**, en [Ideas](Foro-Ideas).

## Qué conviene incluir

| Dato | Cómo se obtiene |
|---|---|
| **Versión** | Ayuda → Acerca de (o `Imaginteca.exe --version`) |
| **Sistema** | Windows 11 / Linux / macOS (y si es Apple Silicon o Intel) |
| **Qué querías conseguir** | una frase: «quiero 150 imágenes listas para un LoRA» |
| **Qué has probado** | «con otro booro sí», «sin Modo IA también»… |
| **Informe** | `Imaginteca.exe --selftest` → genera **`selftest.txt`** |
| **Registro del día** | `%USERPROFILE%\.imaginteca\logs\app-AAAA-MM-DD.log`<br>(Linux/macOS: `~/.imaginteca/logs/…`) |

> 🔐 **Borra tus claves** del registro antes de pegarlo. En `selftest.txt` no hay
> ninguna.

## Plantilla

```markdown
**@tu-usuario** · AAAA-MM-DD

**Necesito:** (qué quieres conseguir)

**Qué he probado:** 

**Versión y sistema:** Imaginteca (tu versión: Ayuda → Acerca de) · Windows 11

**Adjunto:** selftest.txt · líneas del registro del día
```

---

## Mensajes

**@autor** · 2026-10-09

**Necesito:** dejar esto abierto para que cualquiera pregunte lo que quiera.

**Qué he probado:** nada, estrena el hilo 🙂

**Versión y sistema:** Imaginteca (tu versión: Ayuda → Acerca de) · Windows 11

**Adjunto:** —

> Pulsa **✏️ Edit** arriba, baja hasta aquí, copia la plantilla y **añade tu
> mensaje al final**. Guarda con **Save page**.
