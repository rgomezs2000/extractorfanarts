# 👋 Foro · Presentaciones

**Para qué:** presentarte y contar qué coleccionas, de qué plataformas sueles tirar
y qué quieres montar (una colección ordenada, un dataset para entrenar…). Sirve
para conocerse y para que las respuestas se ajusten a lo que buscas.

No es obligatorio presentarse para preguntar, pero ayuda. 🙂

## Plantilla

```markdown
**@tu-usuario** · AAAA-MM-DD

**Quién soy:** (lo que quieras contar; no hace falta ningún dato personal)

**Qué colecciono:** (personajes, estilos, franquicias…)

**De dónde suelo tirar:** (Danbooru, Gelbooru, fediverso, Pixiv…)

**Para qué lo uso:** (archivo personal, un dataset para un LoRA…)

**Versión y sistema:** Imaginteca (tu versión: Ayuda → Acerca de) · Windows 11
```

> **Consejo de privacidad:** no hace falta que pongas tu nombre real, tu correo ni
> dónde vives. Con tu usuario de GitHub basta.
